常见问题

更清楚地
认识 PCCS。

PCCS 是做什么的？
PCCS 是一家以工程为核心的集团，从纤维与面料、设计开发，到成衣、标识、质量与交付，专注于技术运动服装的完整制造链。
“以工程，创造可能”是什么意思？
这代表我们把每一份需求都当成需要精准解决的问题，把设计、材料、技术开发、生产、质量与交付连接成一套完整体系。
PCCS 掌握哪些产品环节？
从概念与技术规格，到面料开发、纸样与样品、辅料与标识、测试与合规、生产与质量控制，再到后整与交付。
除了服装，PCCS 还做什么？
集团还通过 La Prima 涉足医疗与健康业务，通过 EZFY 涉足融资与保险业务，并拥有企业架构中列出的其他集团业务。
PCCS 在哪里运营？
PCCS 的综合运营版图覆盖马来西亚、中国、柬埔寨与越南，并在区域内开展集团及商业活动。
PCCS 如何保证质量？
质量从裁剪开始融入，而不是最后才检验。我们进行产线在线检验、生产途中抽检，以及出货前终检；中国产能服务中国市场，柬埔寨与越南面向西方市场。
PCCS 背后有多少技术能力？
已批准的能力摘要记录了 50 项以上专利、100 多名研发人员、每年约 1,800 款款式，以及每年约 67,000 个样品。
客户需要带来什么？
客户可以带来需求、草图或参考样式。PCCS 会把起点转化为技术方案、工厂可执行的生产资料，以及供客户确认的样品。
PCCS 从什么时候开始做可持续报告？
PCCS 从 FY2018 起按照马来西亚交易所标准进行可持续报告。网站展示的是已报告、经审计的指标，而不是未经验证的目标。
目前展示哪些可持续指标？
目前摘要包括 4,659.20 吨 CO₂e 温室气体排放、55,813.15 吉焦能源，以及 187 万千瓦时可再生太阳能。
参考了哪些框架与认证？
当前参考清单包括 GRS、RCS、OEKO-TEX、ZDHC、Higg FEM、WRAP 金奖 2025、柬埔寨绿色工业奖 2025（银奖），以及 GRI 与 GHG Protocol 等报告框架。
