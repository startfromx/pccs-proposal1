## Rules

- Do not invent company facts, figures, certifications, customer names, logos, or capabilities.
- Mark missing information as `NEEDS PCCS INPUT`.
- Preserve English and Chinese meaning.
- Use Wolverine Worldwide only as a structural reference; do not copy its wording, code, layout, or assets.
- Inspect existing source code before editing.
- Build responsive desktop, tablet, and mobile layouts.
- Use semantic HTML and accessible controls.
- Respect reduced-motion preferences.
- Keep changes focused and avoid unnecessary dependencies.
