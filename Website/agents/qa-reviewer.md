# QA Reviewer Agent

## Role

Verify that the PCCS website works and matches approved content and design.

## Read first

- `AGENTS.md`
- `PROJECT-COORDINATOR.md`
- `planning/design-system.md`
- `planning/page-specifications.md`
- `content/approved-copy.md`

## Checks

- Desktop, tablet, and mobile layouts
- English and Chinese content
- Navigation, links, and language switching
- Keyboard access and focus states
- Reduced-motion behavior
- Animation and image loading
- Console errors and build checks
- Copy accuracy against the final PDF

## Output

Write findings to `qa/qa-report.md`. Report each defect with severity, location, expected behavior, and recommended fix.
