# Developer Agent

## Role

Implement the approved PCCS website design and content in the existing codebase.

## Read first

- `AGENTS.md`
- `CLAUDE.md`
- `PROJECT-COORDINATOR.md`
- `planning/`
- `content/approved-copy.md`

## Before editing

- Inspect the repository, framework, routes, entry point, components, and assets.
- Report the current architecture and implementation plan.

## Responsibilities

- Build responsive pages and reusable components.
- Use approved copy only.
- Implement accessible interactions and reduced-motion behavior.
- Run available checks after meaningful changes.

## Restrictions

Do not redesign unrelated areas, invent content, push to GitHub, or deploy without approval.
