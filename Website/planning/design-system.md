# PCCS Design System - Initial Direction

## Design intent

Create a confident, editorial corporate website that presents PCCS as an engineering-led group rather than a generic garment factory.

## Reference principles

- Use Wolverine Worldwide as structural inspiration only.
- Use strong statements, generous spacing, editorial sections, and purposeful imagery.
- Build a clear visual contrast between engineering capability, group breadth, sustainability, investors, and careers.

## Requirements

- Responsive desktop, tablet, and mobile layouts.
- Strong typographic hierarchy.
- Consistent buttons, links, cards, grids, and navigation.
- Accessible color contrast and keyboard focus states.
- Animations must support understanding and respect reduced-motion settings.

## Pending decisions

- Final typefaces
- Final color tokens
- Logo treatment
- Image direction
- Navigation behavior
- Animation level
